# Paper figures

Current calibrated-data figures use frozen measurements and actual local WSClean
FITS outputs. PNGs support Markdown; SVG/PDF diagrams and charts support the PDF.

| Figure | Stem | Content and evidence |
| --- | --- | --- |
| 1a | `grouping` | Conceptual whole-spectrum permutation and baseline/frequency block boundaries; illustrative 2×4 blocks, with actual 128×48 settings stated in the caption |
| 1b–2 | `epsd-method`, `epsd-levels` | Grouping, precision selection and unsigned power-spaced levels; method schematics |
| 3–4 | `epsd-rate`, `epsd-bits` | Three fixed epsilon-D values: image errors, sample and payload precision fractions; `reports/calibrated-epsd-dense.json` |
| 5–6 | `epsd-images`, `epsd-zoom` | 2×3 panels: recovered I above percentage differences, one epsilon per column; original measured FITS and reference-peak crops |
| 7–8 | `epsd-v-images`, `epsd-v-zoom` | Matching 2×3 Stokes V comparisons across all three epsilon values; `reports/calibrated-epsd-v.json` and new first-run FITS |
| 9 | `epsd-rate-distortion` | Initial I image-error/size relation and physical byte categories; dense-ladder report |

I flux images use viridis; V and signed differences use bwr. Figures 5–6 show
`100 × (I_quant − I_ref) / RMS(reference residual)` with a percentage
colour scale. Figures 7–8 apply the same formula to V. The denominator is the
uncentred reference residual RMS over the full fixed above-10° mask:
1.031244811 Jy/beam for I and 0.384439444 Jy/beam for V. Within each polarization,
it is shared across all cases and zooms. The figures share intensity/difference limits;
the difference scale is fixed at −30% to +30%, with colourbar extensions marking
values beyond the displayed range.
Top-row x axes and y axes in columns 2–3 are hidden; colourbar labels use the
compact `(I_quant − I_ref)/RMS_residual` or V equivalent, with percentage ticks.
All image metrics use the fixed above-10° mask. Figure 9 retains
RMS(image−reference)/RMS(reference residual) on its left axis.

The old combined I/V panels are removed from the paper. The previous Figure 10
speed chart is replaced by tables of measured phases from the median 72.685-second
run; `reports/calibrated-runtime-breakdown.json` records the additive wall times
and the separately reported parallel-work totals.

From the repository root:

```bash
PYTHONPATH=src:scripts python scripts/update_calibrated_paper.py
python scripts/compile_paper.py
```

The update command reads saved reports and local FITS; it does not run imaging or
benchmarks. Use `--skip-images` when local FITS are unavailable to refresh text and
tables while retaining committed image figures. Method diagrams can
be regenerated with `PYTHONPATH=scripts python -c 'from build_epsd_figures import methods; methods()'`.
The existing grouping schematic is generated by `grouping()` in
`scripts/build_paper_figures.py`; its PNG, SVG and PDF versions are retained.

Other figure files are retained for the preserved initial manuscript and earlier
development studies. They are not new measurements in the current paper.
